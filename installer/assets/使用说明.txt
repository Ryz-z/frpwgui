一、这是什么
----------------------------------------------------------------------
FrpWin 是一套把 frp（https://github.com/fatedier/frp）打包成 Windows
原生程序的工具集。装完之后你得到三样东西：

  FrpWin.exe   图形化管理器，双击就能用，负责配置和启停（桌面有快捷方式）
  frps.exe     服务端，装在有公网 IP 的机器上
  frpc.exe     客户端，装在需要被外网访问的内网机器上

和直接用官方命令行版本相比，这个版本多了：
  · 全中文图形界面，不用手写配置文件
  · 一键把 frps / frpc 注册成 Windows 服务，开机自动运行、崩溃自动重启
  · 一键在防火墙里放行端口
  · 实时查看运行日志
  · 服务端自带 Web 管理面板（浏览器就能看谁连上来了、跑了多少流量）


二、五分钟跑通
----------------------------------------------------------------------
【第一步】在“有公网 IP 的服务器”上安装并配置服务端

  1. 运行 setup.exe 完成安装，双击桌面的“FrpWin 内网穿透套装”；
  2. 切换到「服务端（frps）」标签页；
  3. 确认「监听端口 bindPort」= 7000（默认值，不用改）；
  4. 把「认证令牌 token」改成一串自己的复杂密码，记下来，客户端要用；
  5. 点「保存并启动服务端」；
  6. 点「放行防火墙端口」，让 7000 端口能从外网访问；
  7. 想让它开机自动跑：点「安装为 Windows 服务」。

  提示：把服务器公网 IP 和 token 告诉需要连接的客户端。

【第二步】在内网机器上配置客户端

  1. 安装并打开 FrpWin，切换到「客户端（frpc）」标签页；
  2. 「服务器地址」填服务器的公网 IP，「服务器端口」填 7000；
  3. 「认证令牌」填得和服务器一模一样（一个字符都不能差）；
  4. 在「代理规则」表格里添加一行，例如要穿透远程桌面：
        名称 = rdp        类型 = tcp
        本地IP = 127.0.0.1   本地端口 = 3389   远程端口 = 13389
  5. 点「保存并启动客户端」。

【第三步】开始使用

  在任何一台能上网的电脑上，打开远程桌面，连接：
        服务器公网IP : 13389
  就连到内网那台机器的 3389 了。


三、常见穿透场景怎么填
----------------------------------------------------------------------
【远程桌面 / SSH / 数据库等 TCP 服务】
  类型 tcp，本地端口填服务端口（3389 / 22 / 3306），远程端口随便挑一个没被占用的。

【网页 / 网站（HTTP）】
  服务端要先填上「HTTP 虚拟主机端口」（比如 80）；
  客户端类型选 http，本地端口填网站端口（如 80），自定义域名填你的域名；
  再到域名服务商那里，把该域名的 A 记录解析到服务器公网 IP。

【UDP 服务（DNS、部分游戏）】
  类型选 udp，其余和 tcp 一样。

【不想暴露公网端口（点对点）】
  用 stcp：客户端类型选 stcp，会自动生成 secretKey；
  访问方在「访问者」表格里添加一行，serverName 填前面的代理名，secretKey 填一样的，
  然后访问 127.0.0.1:本地绑定端口 即可。
  想更快（NAT 合适时直连、不走服务器中转）就把 stcp 换成 xtcp。


四、端口说明
----------------------------------------------------------------------
  7000     frps 与 frpc 之间的控制端口，必须放行
  7500     frps 的 Web 管理面板，浏览器访问 http://服务器IP:7500
  13389 等 你自己在代理规则里设置的“远程端口”，每一个都要在服务端放行

  放行端口两种办法：
    · FrpWin「服务端」页 →「放行防火墙端口」（会自动放行上面填的所有端口）
    · 手工：控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则 → 新建规则


五、安全提醒（很重要）
----------------------------------------------------------------------
  1. 一定要设置复杂的 token。没有 token 或 token 太简单，任何人都能拿你的
     服务器当中转，甚至把流量算在你头上。
  2. frps 的 7000 端口不要对整个互联网敞开，尽量限制来源 IP。
  3. Dashboard 默认账号密码是 admin/admin，请务必修改；
     或者把 Dashboard 端口设为 0 直接关掉。
  4. 本软件不会收集任何信息，所有配置和日志都在你自己电脑上。


六、文件都放在哪
----------------------------------------------------------------------
  程序目录：  C:\Program Files\FrpWin\
              FrpWin.exe / frps.exe / frpc.exe / 使用说明.txt

  配置目录：  C:\ProgramData\FrpWin\
              frps.toml    服务端配置文件（图形界面自动生成）
              frpc.toml    客户端配置文件（图形界面自动生成）
              ui-settings.xml  图形界面的设置
              logs\        以 Windows 服务方式运行时的日志

  在 FrpWin 界面点「打开数据目录」可以直接跳到配置目录。


七、常见问题
----------------------------------------------------------------------
  Q：客户端一直连不上服务端？
  A：按顺序检查：① 服务器公网 IP 是否填对；② token 是否两侧完全一致；
     ③ 服务器防火墙和安全组是否放行了 7000（云服务器还要在控制台的安全组里放行，
     Windows 防火墙放行 ≠ 云安全组放行）；④ 服务端是否已经启动。

  Q：客户端显示登录成功，但外面连不上映射出来的端口？
  A：说明控制端口通了，但“远程端口”没放行。到服务端把对应的远程端口也放行一次。

  Q：怎么卸载？
  A：控制面板 → 程序和功能 → FrpWin 内网穿透套装 → 卸载。
     卸载会顺带停止并删除相关的 Windows 服务、清理防火墙规则；
     配置和日志会保留在 C:\ProgramData\FrpWin，需要的话可以自己删。

  Q：绿色免安装版怎么用？
  A：把三个 exe 放在同一个文件夹里，双击 FrpWin.exe 即可。
     配置会写到 C:\ProgramData\FrpWin（若没有写权限则写到当前用户目录）。
